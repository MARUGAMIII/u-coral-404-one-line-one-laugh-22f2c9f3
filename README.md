A single hilarious line for make.fun's "One Line, One Laugh" bounty ($2 in USDC). The line flips the life-coach premise on its head: the client hires a coach to fix his life, and the coach fires the client instead, holding an exit interview that names the client himself as a hostile work environment.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
